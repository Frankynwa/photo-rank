- API 路由统一使用 `@app.get/post/delete` 装饰器并以 async 函数定义，参数通过 FastAPI 类型注解自动解析（如 `UploadFile`、路径参数）。
- WebSocket 事件通过统一的 `type` 字段区分（如 `upload_complete`、`analysis_start`、`analysis_complete`、`analysis_error`），前端用 switch 分支处理。
- 文件操作前统一检查路径是否存在并通过 `HTTPException` 返回 404 或抛出异常，避免裸异常泄露。
- 长耗时任务（分析流水线）通过 WebSocket 广播中间状态，而非阻塞 HTTP 响应，保持接口即时返回。
- 路径构造统一使用 `pathlib.Path` 拼接 `BASE_DIR / sub_dir` 形式，保证跨平台兼容性。
