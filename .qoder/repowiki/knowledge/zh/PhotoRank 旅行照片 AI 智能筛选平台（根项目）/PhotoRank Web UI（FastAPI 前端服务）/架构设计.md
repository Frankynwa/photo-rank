模块以单文件 FastAPI 应用 `main.py` 为入口，通过 `uvicorn.run(app, host="127.0.0.1", port=8000)` 启动；静态 HTML 模板 `templates/index.html` 由 `/` 路由直接返回文本，不依赖 Jinja2 渲染引擎。

- 路由层：REST API 集中在 `/api/*` 命名空间下，包括上传（`/api/upload`）、照片 CRUD（`/api/photos`）、结果读取（`/api/results/{platform}`）和分析触发（`/api/analyze`），以及根路径 `/` 返回主页。
- 实时通信：通过 `ConnectionManager` 类维护活跃 WebSocket 连接池，在上传完成、分析开始/完成/错误等节点通过 `manager.broadcast()` 向所有客户端推送结构化消息（`type` 字段区分事件）。
- 数据持久化：照片存入 `uploads/` 目录，分析结果按平台分目录写入 `output/{platform}/ranking.json`，由 `/api/results` 路由读取。
- 业务解耦：分析逻辑通过 `from core.pipeline import run_pipeline` 延迟导入调用，Web 层仅负责编排与广播，不内嵌算法实现。
- 配置集中：`config.py` 统一管理项目路径、分类标签、平台定义、各层阈值及 Qwen-VL API 地址，但当前 `main.py` 未引用该模块，存在配置冗余。
