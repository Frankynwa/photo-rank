根目录作为整个项目的装配层：main.py 启动 Web UI（FastAPI + Uvicorn），同时加载 config.py 中的平台配置与环境变量（.env 中的 QWEN_API_KEY 等），驱动 core/ 下的五层流水线（layer1~layer5 + pipeline.py）完成从上传到输出的端到端处理；uploads/ 和 output/ 作为共享数据目录被 Web UI 与核心流水线共同读写；docs/research/ 存放支撑各层模型选型与框架对比的研究报告。三层子模块通过 Python 包导入与配置文件解耦，无运行时进程间通信，所有调用均通过函数级 API 在同一个 Python 进程中完成。
