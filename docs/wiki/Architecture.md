# 架构设计

本文档介绍 PhotoRank 的系统架构和设计理念。

## 设计目标

1. **可验证性** — 每层独立可测试
2. **可扩展性** — 易于添加新模型/平台
3. **可维护性** — 代码清晰，文档完整
4. **高性能** — RTX 5070 CUDA 加速

## 各层详解

### Layer 1: 客观指标

**目标**: 淘汰技术质量差的照片

**算法**:
- **清晰度**: 拉普拉斯方差（Laplacian Variance）
  - 计算图像梯度的方差
  - 方差越大，图像越清晰
- **曝光**: 直方图分析
  - 过曝: 亮部像素 > 30%
  - 欠曝: 暗部像素 > 50%
- **噪声**: 信噪比（SNR）
  - 信号 / 噪声标准差

**阈值**:
- 清晰度 > 100
- 曝光 < 30% 过曝
- 噪声 < 50% 欠曝

### Layer 2: 相似聚类

**目标**: 同一场景多张照片选最佳

**算法**: 感知哈希（pHash）
1. 缩放到 32x32
2. 转为灰度
3. DCT 变换
4. 取左上 8x8
5. 计算均值
6. 生成 64 位哈希

**阈值**: 汉明距离 ≤ 10

**选择**: 每组选清晰度最高的代表

### Layer 3: 审美评分

**目标**: 按审美质量排序

**模型**: NIMA-VGG16（AVA 数据集训练）
- **AVA 数据集**: 255K 张照片，每张 ~200 人评分
- **SRCC**: 0.71（Spearman 秩相关系数）
- **分数范围**: 1-10
  - < 4.5: 废片
  - 4.5-5.0: 普通
  - 5.0-5.5: 中等偏好
  - 5.5-6.0: 好看
  - > 6.0: 很好看

**推理**: RTX 5070 CUDA，0.09GB 显存

### Layer 4: 人脸质量

**目标**: 检测人脸质量问题

**模型**: MediaPipe Face Landmarker v1.0
- **478 个关键点**: 3D 坐标
- **52 个 blendshape**: 表情分析
- **检测**:
  - 闭眼: `eyeBlinkLeft` / `eyeBlinkRight` > 0.5
  - 微笑: `mouthSmileLeft` / `mouthSmileRight`
  - 人脸清晰度: 拉普拉斯方差

### Layer 5: 深度分析

**目标**: 提供深度分析和文案

**模型**: Qwen-VL Max API
- **分类**: 8 类（风景/人像/人文/美食/夜景/自拍/合照/其他）
- **构图解读**: 三分法/引导线/对称等
- **改进建议**: 裁剪/调色/角度
- **情绪图谱**: 快乐/宁静/震撼等
- **文案生成**: 平台定制，15-30 字

## 数据流

```
输入照片
    │
    ▼
Layer 1: 客观指标
    │
    ├─ 淘汰: 模糊/过曝/欠曝
    │
    ▼
Layer 2: 相似聚类
    │
    ├─ 合并: 同类选最佳
    │
    ▼
Layer 3: 审美评分
    │
    ├─ 排序: 按分数排序
    │
    ▼
Layer 4: 人脸质量
    │
    ├─ 调整: 闭眼扣分
    │
    ▼
Layer 5: 深度分析
    │
    ├─ 分析: 分类/构图/改进/情绪/文案
    │
    ▼
输出结果
    │
    ├─ 精选照片（Top 12）
    ├─ 评分（审美分/综合分）
    ├─ 深度分析（分类/构图/改进/情绪/文案）
    └─ 排名（ranking.json）
```

## 扩展性

### 添加新模型

1. 在 `core/` 目录创建新文件
2. 实现评分函数
3. 在 `core/pipeline.py` 中集成
4. 添加测试

### 添加新平台

1. 编辑 `config.py` 中的 `PLATFORMS` 字典
2. 更新 `core/layer5_analysis.py` 中的文案生成 prompt
3. 更新 Web UI 中的平台选择器
4. 添加测试

## 性能优化

### GPU 显存优化

- **NIMA-VGG16**: 0.09GB
- **MediaPipe**: CPU 推理
- **Qwen-VL**: API 调用

### 并行处理

- Layer 1-2: CPU 并行
- Layer 3: GPU 串行
- Layer 4: CPU 并行
- Layer 5: API 串行
