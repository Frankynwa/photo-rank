# 架构设计

本文档介绍 PhotoRank 的系统架构和设计理念。

## 设计目标

1. **可验证性** — 每层独立可测试
2. **可扩展性** — 易于添加新模型/平台
3. **可维护性** — 代码清晰，文档完整
4. **高性能** — RTX 5070 CUDA 加速

## 各层详解

### Layer 1: 客观指标

**目标**: 淘汰技术质量差的照片

**算法**:
- **清晰度**: 拉普拉斯方差（Laplacian Variance）
  - 计算图像梯度的方差
  - 方差越大，图像越清晰
- **曝光**: 直方图分析
  - 过曝: 亮部像素 > 30%
  - 欠曝: 暗部像素 > 50%
- **噪声**: 信噪比（SNR）
  - 信号 / 噪声标准差

**阈值**（见 `config.py`，实测调优）:
- 清晰度（拉普拉斯方差）> 70
- 过曝像素占比 > 0.4、欠曝像素占比 > 0.8

### Layer 2: 相似聚类

**目标**: 同一场景多张照片选最佳

**算法**: 感知哈希（pHash）
1. 缩放到 32x32
2. 转为灰度
3. DCT 变换
4. 取左上 8x8
5. 计算均值
6. 生成 64 位哈希

**阈值**: 汉明距离 ≤ 16，且限定同一天拍摄（防跨日期误合并）

**选择**: 每组按清晰度保留 2 张代表（连拍次佳也参与审美竞争）

### Layer 3: 审美评分

**目标**: 按审美质量排序（大众审美评分）

**模型**（v2.0.0 升级，原 NIMA-VGG16 已弃用）:
- **TOPIQ-IAA**: GPU 推理，批次归一化，模块级模型缓存 + 显存分时加载
- **VLM 多维度评分**: rubric 驱动的精细化评分（构图/色彩/光影），带重试与结果校验，按平台权重加权

**融合**: VLM 分 + TOPIQ + L1 清晰度 + L4 人脸四路融合，权重总和恒为 1.0：
- VLM 已评分时，人脸因素已被 VLM 基于 L4 注入信息消化，face 权重归零重分配
- VLM 未评分（降级路径）时保留 face 权重；无脸照片自动重分配人脸权重

### Layer 4: 人脸质量

**目标**: 检测人脸质量问题

**模型**: MediaPipe Face Landmarker v1.0
- **478 个关键点**: 3D 坐标
- **52 个 blendshape**: 表情分析
- **检测**:
  - 闭眼: `eyeBlinkLeft` / `eyeBlinkRight` > 0.5
  - 微笑: `mouthSmileLeft` / `mouthSmileRight`
  - 人脸清晰度: 拉普拉斯方差
  - 硬伤钳制: 检出硬伤时对评分施加上限约束

### 视频处理（v2.0.0 新增）

**目标**: 从视频中选出精彩瞬间

**流程**（`core/video_frames.py`）:
1. 流式抽帧（1s 间隔）
2. L1/L2/L4 本地快筛（不调 VLM，省 API 成本）
3. 合格帧进入完整流水线
4. 照片/视频各自独立榜单

### 增量模式（v2.0.0 新增）

`run_pipeline(incremental=True)` 时基于 checkpoint 判重，只处理新增照片；与 `rerun_layers` 互斥（同时传入时 incremental 优先）。

## 数据流

```
输入照片/视频
    │
    ├─（视频）流式抽帧 → L1/L2/L4 快筛 → 合格帧进流水线
    │
    ▼
Layer 1: 客观指标
    │
    ├─ 淘汰: 模糊/过曝/欠曝
    │
    ▼
Layer 2: 相似聚类
    │
    ├─ 合并: 每组保留 2 张代表
    │
    ▼
Layer 3: 审美评分（TOPIQ + VLM 四路融合）
    │
    ├─ 排序: 按融合分排序
    │
    ▼
Layer 4: 人脸质量
    │
    ├─ 调整: 闭眼/硬伤钳制
    │
    ▼
输出结果
    │
    ├─ 精选照片（Top 12）与视频双榜单
    ├─ 评分（审美分/综合分 + 分项明细）
    ├─ 标签与建议（VLM 产出）
    └─ 排名（ranking.json）
```

## 扩展性

### 添加新模型

1. 在 `core/` 目录创建新文件
2. 实现评分函数
3. 在 `core/pipeline.py` 中集成
4. 添加测试

### 添加新平台

1. 编辑 `config.py` 中的 `PLATFORMS` 字典（name/style/output_count/weights）
2. 权重用于 Layer 3 VLM 评分的加权融合，四项权重总和恒为 1.0
3. 添加测试

## 性能优化

### GPU 显存优化

- **TOPIQ-IAA**: 模块级缓存 + 显存分时加载（`release_topiq_model`）
- **MediaPipe**: CPU 推理
- **VLM**: API 调用（带重试）

### 并行处理

- Layer 1-2: CPU 并行
- Layer 3: GPU 串行（TOPIQ）+ VLM API 并发
- Layer 4: CPU 并行
